# Telegram-бот «Что посмотреть вечером»

Telegram-бот для подбора фильмов по жанру, рейтингу и году выпуска.

## Возможности

- подбор фильма по жанру;
- фильтр по диапазону рейтинга;
- фильтр по году выпуска;
- показ постера фильма;
- ссылки на КиноПоиск и TMDB;
- кнопка «Другой фильм»;
- защита от повторов в рамках текущего запуска;
- добавление фильма в избранное;
- просмотр избранного;
- удаление конкретного фильма из избранного;
- хранение избранного в SQLite.

## Используемые технологии

- Python
- aiogram
- aiohttp
- python-dotenv
- SQLite
- TMDB API
